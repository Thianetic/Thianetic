## 🚀 Proyectos Destacados & Casos en Producción

### 🏢 SaaS Registro Horario SITH — *Producción B2B*
> **Solución multi-empresa para el registro digital de jornada laboral y gestión de incidencias.**
- **Arquitectura:** Frontend modular en Vanilla JS, panel web administrativo corporativo, API RESTful con DB dockerizada y app móvil nativa en Android.
- **Alcance:** Aprovisionamiento y securización del servidor en producción, orquestación de servicios y despliegue de instancias para empresas cliente.
- **Stack:** `Debian` `Docker` `Nginx` `PHP` `MariaDB` `Android`

### 🌾 Plataforma IoT de Telemetría Agroindustrial — *Producción M2M*
> **Sistema distribuido de supervisión y dosificación remota para maquinaria de alimentación agropecuaria.**
- **Arquitectura:** Broker MQTT con autenticación estricta, emulador software de hardware para pruebas de carga y estrés, dashboard de supervisión y app nativa Android para monitorización y control en tiempo real.
- **Alcance:** Flujo continuo de telemetría y ejecución de comandos con tolerancia a caídas de red.
- **Stack:** `Python` `Broker MQTT` `Docker` `Android` `Linux Hardened`

### 🎫 TicketApp — Sistema Integral de Ticketing & Incidencias
> **Proyecto de desarrollo de aplicaciones multiplataforma (DAM) evaluado con 10/10 y Matrícula de Honor.**
- **Arquitectura:** MVP Full-Stack integral compuesto por app nativa Android, panel web de administración corporativo, API RESTful y capa de persistencia polimórfica intercambiable (SQLite local, servidor relacional autoalojado MariaDB/MySQL o Cloud Firebase).
- **Stack:** `Android` `PHP REST` `Panel Web` `SQLite / MariaDB` `Firebase`

### ⚡ Troposfera Services
> **Microservicio especializado en orquestación de eventos temporales y captura de series analíticas.**
- **Arquitectura:** Microservicio reactivo de alta concurrencia para temporización de eventos y plataforma de procesamiento de telemetría meteorológica asíncrona en Python con soporte REST y WebSockets.
- **Stack:** `Python` `FastAPI` `WebSockets` `Series Temporales`

### 🔒 Ciberseguridad & Herramientas de Red en Python
- **Port-Scan:** Escáner de puertos TCP multihilo y fingerprinting de servicios para auditorías de superficie de exposición.
- **Py-Devkiller:** Utilidad CLI de sistema para detección y purga segura de procesos huérfanos que retienen sockets de red.
- **Own-Cipher-Book:** Gestor seguro de contactos y credenciales bajo arquitectura local Zero-Knowledge con cifrado simétrico en reposo.

## 🔬 Cluster & Laboratorio de Telemetría IoT / Hardware

Entorno de ingeniería enfocado al testeo de resiliencia, comunicaciones distribuidas y diseño electrónico:

- **Infraestructura de Nodos ARM64:** Clúster de cómputo Linux bajo arquitectura ARM64 operando servicios de red 24/7, pasarela de comunicaciones **Zigbee2MQTT** con filtrado local y broker centralizado **Mosquitto** con autenticación criptográfica.
- **Firmwares de Ultra Bajo Consumo & Sensores:** Desarrollo sobre microcontroladores con ciclos de suspensión profunda (*Deep Sleep*), sensores de telemetría ambiental (I2C/SPI) y lectura por proximidad mediante módulos **NFC/RFID**.
- **Integración Electrónica & Diagnóstico:** Capacidad demostrada en ensamblaje, diagnóstico a nivel de componente electrónico y mantenimiento preventivo de hardware.
